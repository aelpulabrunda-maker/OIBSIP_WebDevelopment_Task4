# Login Authentication Web Application

## Objective
To develop a simple Login Authentication Web Application using HTML, CSS, and JavaScript that allows users to sign up and log in with basic validation.

## Tools Used
- HTML
- CSS
- JavaScript

## Features
- User Sign Up and Login
- Form validation
- Error message handling for invalid inputs
- Simple and responsive interface

## Outcome
The Login Authentication Web Application was successfully developed and helps users understand basic authentication flow and form validation in web development.
